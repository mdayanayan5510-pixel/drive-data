BCA Major Project · 2026–2027

Drive Data — Car Sales & Price Analysis System

A data-driven resale valuation and market intelligence platform. The planned system combines data preprocessing, exploratory data analysis, machine learning and an interactive web interface for vehicle inputs, analysis and price estimation.

Project objectives

  • Prepare and clean used-car sales/pricing data.
  • Explore trends and feature correlations.
  • Compare Linear Regression, Decision Tree and Random Forest.
  • Evaluate models using R², MAE and RMSE.
  • Present insights in a responsive dashboard.

Technology stack

  • Python 3.10+
  • Pandas and NumPy
  • Scikit-learn and Joblib
  • Matplotlib / Seaborn
  • Streamlit or Flask for production integration
  • HTML, CSS and JavaScript prototype
Current version: responsive front-end prototype with browser-only demo login, dashboard, market-analysis plan and illustrative estimate calculator. It supports manual CSV upload and a rule-based demo estimate, but does not yet have a secure server, MySQL database, automated image recognition, a trained ML model, or automatic email sending.
